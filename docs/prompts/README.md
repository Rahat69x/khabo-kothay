# Prompts Sequence & Roadmap

This folder documents the prompts used across development stages of "Khabo Kothay?":

1. `01-day1.md` - Day 1: Project hygiene, thin vertical slice, data check, PWA, fare tuning, feedback loop.
2. `02-master-web.md` - Master web application features, routing comparison, weather, expanded cuisines.
3. `03-personalization.md` - Bandit personalization, contextual bandit weights, taste profile learning.
4. `04-android.md` - Expo React Native Android mobile app with English and Bangla parity.
5. `05-test-rebrand-apk.md` - Rebranding to "Khabo Kothay?", rigorous test suite, APK building.
6. `06-locations.md` - Complete Dhaka location database and hierarchical discovery.
7. `07-brand-theme.md` - Brand design system: Indigo & Saffron across web, mobile, logos, and dark mode.
8. `08-future.md` - Future enhancements, public release roadmap, and scalability plans.
